# 자동 테스트

프로젝트 최상위에서 실행합니다.

```powershell
python -m unittest discover -s tests -v
```

Python 표준 unittest를 사용합니다. 실제 MQTT / MySQL 접속이나 인증정보 없이 실행하며 서버 및 실제 상태 파일을 변경하지 않습니다.

- 환경변수 우선순위 / 서비스 계정 / 장비별 상태 경로
- 명령 TTL 300초 / 만료 / 검사 순서 / 온도 반올림
- apply 만료 전달 / JSON 검증 / retain 제한 / 측정값 검증
- 고온 경계 / 예측 대기 시간 / 데이터 지연 / 문 재개방
- 통합 실행 설정 오류 시 프로세스 시작 방지

실제 브로커 ACL / TLS / MySQL 트랜잭션 / 재시작 후 재전송 / 웹 조작은 이 테스트로 검증하지 않습니다. 배포 환경 통합 시험이 별도로 필요합니다.

자동 테스트는 별도의 환경변수나 실제 인증정보 없이 실행합니다. 테스트 내부에서 임시 설정값을 전달하며, 실제 MQTT / MySQL 서버에 연결하지 않습니다.
